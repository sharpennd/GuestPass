# GuestPass
GuestPass is a lightweight Paper plugin that allows server administrators to place players into a protected guest mode. It is ideal for visitors, new players, content creators, staff members, builders showcasing projects, or anyone who needs temporary access without the ability to affect the world.

Features:
- Prevents all player damage
- Stops hunger depletion
- Blocks interaction with blocks and entities
- Prevents breaking and placing blocks
- Allows guests to freely explore the server
- Lets guests continue chatting normally
- Lightweight and easy to use
- Compatible with modern Paper servers

GuestPass provides a simple and reliable way to let players safely explore your server without the risk of griefing, accidental changes, or unwanted interactions. Whether you're running a survival server, creative world, roleplay community, or public hub, GuestPass makes visitor management straightforward and hassle-free.
